## Key Technical Decisions
- **Database**: Firestore collections for workouts, rounds, settings, achievements
- **State Management**: React hooks + Firebase real-time listeners
- **UI Framework**: shadcn/ui components with custom glassmorphism styling
- **Timer Logic**: Complex 5-round structure with exercise transitions
- **Real-time Updates**: Firebase onSnapshot listeners throughout app

## Simplicity Approach
Each task will be implemented as a single, focused change:
- One component at a time
- One page at a time
- One Firebase operation at a time
- Minimal complexity in each step
