## Complete Claude Code Prompt for 10K Swing Kettlebell Tracker (Firebase Version)

**Create a modern Next.js 15 application for tracking the 10,000 Swing Kettlebell Challenge using Google Firebase as the backend database with the following specifications:**

### Core Concept
A fitness tracking app that helps users complete the 10K Swing Challenge - 20 workouts of 500 swings each, alternating with strength exercises. The app should have a beautiful, modern UI with glassmorphism effects and animated gradients, powered by Firebase Firestore for real-time data synchronization.

### Technical Stack
- **Framework**: Next.js 15 with App Router and TypeScript
- **Styling**: Tailwind CSS v4 with custom animations and glassmorphism effects
- **UI Components**: shadcn/ui components (Card, Button, Badge, Progress, Dialog, etc.)
- **Database**: **Google Firebase Firestore** (NoSQL document database)
- **Firebase SDK**: Firebase v11+ for web
- **Authentication**: Firebase Auth (optional, for future user accounts)
- **Icons**: Lucide React
- **Date Handling**: date-fns
- **Charts**: Recharts for analytics
- **Animations**: Custom CSS animations and tw-animate-css
- **State Management**: React hooks with Firebase real-time listeners

### Firebase Configuration
Set up Firebase with the following services:
- **Firestore Database**: Main data storage
- **Firebase Hosting**: For deployment
- **Firebase Functions**: For server-side operations (optional)

### Firestore Database Structure
The app should use the following collections and document structure:

**Workouts Collection**: Store workout details including date, strength exercise type, kettlebell weight, total time, completion status, and optional notes. Each workout should have a reference to its associated rounds.

**Workout Rounds Collection**: Store individual round data for each workout, including round number (1-5), time in minutes and seconds, and reference to the parent workout.

**User Settings Collection**: Store user preferences including preferred kettlebell weight, challenge start date, and target completion days.

**Challenges Collection**: Track challenge progress including start/end dates, target days, and completion status.
